# pm-data-analytics (产品数据分析)

针对产品经理的数据分析技能：SQL 查询生成和同类群组（Cohort）分析。分析用户数据、生成查询并识别留存模式。

## 技能 (3)

- **ab-test-analysis** —— 通过统计显著性、样本量验证、置信区间和可执行建议来分析 A/B 测试结果。
- **cohort-analysis** —— 对用户参与数据进行同类群组分析。
- **sql-queries** —— 根据自然语言描述生成 SQL 查询。

## 指令 (3)

- `/pm-data-analytics:analyze-cohorts` —— 对用户数据执行同类群组分析 —— 涵盖留存曲线、功能采用和参与趋势。
- `/pm-data-analytics:analyze-test` —— 分析 A/B 测试结果 —— 涵盖统计显著性、样本量验证以及 运行/延长/停止 建议。
- `/pm-data-analytics:write-query` —— 从自然语言生成 SQL 查询 —— 支持 BigQuery、PostgreSQL、MySQL 等。
