# pm-toolkit (产品工具箱)

产品经理辅助工具技能：简历评估、NDA 起草、隐私政策生成以及语法/流畅度检查。针对核心产品工作之外的产品经理必备工具。

## 技能 (4)

- **draft-nda** —— 起草一份详细的两方保密协议（NDA）。
- **grammar-check** —— 识别文本中的语法、逻辑和流畅度错误，并在不重写整个文本的情况下提供针对性修复建议。
- **privacy-policy** —— 为产品起草详细的隐私政策，涵盖数据类型、司法管辖区、合规性考虑以及需要法律审查的条款。
- **review-resume** —— 全面的产品经理简历评估，并基于 10 大最佳实践（包含 XYZ+S 公式、关键词优化、针对职位的定制和结构）进行优化建议。

## 指令 (5)

- `/pm-toolkit:draft-nda` —— 起草一份带有司法管辖区适配条款的两方保密协议。
- `/pm-toolkit:privacy-policy` —— 起草一份涵盖数据收集、使用、存储和合规要求的隐私政策。
- `/pm-toolkit:proofread` —— 检查任何文本中的语法、逻辑和流畅度 —— 提供针对性修复而无需重写。
- `/pm-toolkit:review-resume` —— 基于 10 大最佳实践进行全面的产品经理简历评估 —— 包含结构、影响指标、关键词和可操作的反馈。
- `/pm-toolkit:tailor-resume` —— 根据特定职位描述定制产品经理简历 —— 包含关键词对齐、经验重塑和战略优化。
