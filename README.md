# AI 大模型管理中后台 (前端原型) - Vue3

**⚠️ 说明：本项目目前为纯前端交互原型演示（Prototype），主要用于 UI/UX 体验以及需求前期的沟通确认，暂未对接真实的后端业务 API。**

这是一个基于 Vue 3 架构开发的现代 AI 大模型运营管理中后台原型系统，旨在为企业提供一站式的大模型接入、知识库管理、对话分析及性能监控的交互演示平台。

## 🛠 技术栈

- **核心框架**: Vue 3 (Composition API) + Vite + TypeScript
- **状态管理**: Pinia
- **路由管理**: Vue Router 4
- **UI 组件库**: Element Plus
- **数据可视化**: ECharts (`vue-echarts`)
- **特别集成**: `Pinmark` 网页外挂批注组件 (支持本地开发时的自动批注落盘及 Git 追踪)

## 🌟 核心功能模块

- **AI 对话测试**: 提供实时的大模型交互调试窗口，支持多轮交互。
- **文档分析**: 支持 PDF/Word 等多种文档上传及智能内容解析。
- **知识库管理**: 企业私有数据的上传、切片管理与检索测试。
- **模型实例配置**: 支持多供应商（如 OpenAI、Anthropic、本地模型等）的统一接入与核心推理参数配置（生成温度、Max Tokens等）。
- **企业与租户管理**: 支持对多租户环境的接入管理。
- **数据看板与监控**: 提供直观的 API 调用性能监控及使用量、Token 消耗统计。

## 📦 快速开始

### 1. 安装依赖

请确保您的本地环境中已安装 [Node.js](https://nodejs.org/)。

```bash
npm install
```

### 2. 启动本地开发环境

```bash
npm run dev
```

成功启动后，点击终端提供的本地链接（默认通常为 `http://127.0.0.1:5173`）即可预览项目。
> 提示：本地开发状态下，您可以随时在页面中进行 Pinmark 标记，标记数据会自动保存到 `public/.pinmarks.json` 中。

### 3. 构建生产部署产物

```bash
npm run build
```

构建完成后，所有的静态资源文件将被输出到项目根目录下的 `dist` 文件夹中，您可以将其部署到 Nginx、Vercel 等任何静态托管平台中。
